# GJF PLUS+

Plataforma web educacional para estudo de idiomas, com sistema de autenticação, área do aluno e materiais de apoio em Português, Inglês e Espanhol.

## Funcionalidades

- Cadastro de usuários
- Login com Firebase Authentication
- Área do aluno (Lobby)
- Perfil do usuário com foto e apelido
- Materiais em PDF
- Conteúdos organizados por idioma
- Logout seguro
- Interface responsiva

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Firebase Authentication
- Firebase Firestore
- Firebase Storage
